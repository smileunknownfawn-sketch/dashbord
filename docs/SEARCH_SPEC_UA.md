# Специфікація пошуку

Пошук працює локально та не передає введені дані в мережу.

## Що шукається

- номер розпорядження;
- короткий опис;
- відповідальний;
- категорія;
- пріоритет;
- мітки;
- вихідний номер відповіді;
- текст відповіді;
- назва прикріпленого файла;
- статус.

## Поведінка

Запит нормалізується без урахування регістру. Розділові знаки не заважають пошуку. Запит із кількох слів шукає всі значущі слова. Підтримується частковий збіг: наприклад, `автомоб` знаходить `автомобільної`.

Точний збіг номера має найвищий пріоритет. Збіги сортуються за релевантністю, після чого за номером розпорядження.

## Безпека

Пошук не виконує SQL, shell або мережевих запитів на основі введеного користувачем тексту. Пошук працює лише з уже завантаженими локальними даними.
