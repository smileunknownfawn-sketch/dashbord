# Фінальний контроль інтерфейсу перед EXE

## Українська мова

- технічні назви полів не показуються користувачу;
- `id` → `Ідентифікатор`;
- `number` → `Номер`;
- `deadline` → `Термін виконання`;
- `description` → `Короткий опис`;
- `status` → `Статус`;
- `priority` → `Пріоритет`;
- `responsible` → `Відповідальний`;
- `category` → `Категорія`;
- `outgoing` → `Вихідний номер`;
- усі основні placeholder'и українською;
- повідомлення про успішні дії українською;
- повідомлення про помилки українською.

## Пошук

- номер;
- частина номера;
- окреме слово;
- частина слова;
- кілька слів одночасно;
- відповідальний;
- категорія;
- пріоритет;
- мітки;
- вихідний номер;
- текст відповіді;
- назва файла;
- ранжування за релевантністю.

## Перед EXE

- заміна Streamlit на desktop UI;
- автономний запуск без мережі;
- вибір локальної папки даних;
- перевірка доступу до папки;
- SQLite;
- резервне копіювання;
- відновлення;
- кошик;
- журнал подій;
- діагностика;
- 10 реальних тестових розпоряджень;
- перевірка на чистому Windows-профілі;
- перевірка інсталяції та видалення.
