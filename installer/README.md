# Інсталятор Дашборда розпоряджень 1.0.1

Фінальна поставка має складатися з двох рівнів:

1. `Дашборд_розпоряджень_1.0.1_Setup.exe` — інсталятор програми.
2. `Дашборд_розпоряджень_1.0.1.exe` — самостійний виконуваний файл для portable-запуску.

## Встановлення

Інсталятор встановлює програму в окрему папку та створює ярлики. Робочі дані НЕ повинні зберігатися всередині `Program Files`.

Під час першого запуску програма пропонує вибрати папку даних, наприклад `D:\Дашборд`. У цій папці зберігаються база, розпорядження, відповіді, вкладення, резервні копії та звіти.

## Видалення

Деінсталятор повинен пропонувати:

- видалити лише програму та залишити дані;
- видалити програму й залишити резервну копію;
- видалити програму та дані після окремого підтвердження.

За замовчуванням дані залишаються.

## Мережа

Фінальний desktop-застосунок не повинен вимагати доступу до мережі або Інтернету для штатної роботи. GitHub Actions використовується лише для розробки та складання артефактів, а не програмою на ПК користувача.
