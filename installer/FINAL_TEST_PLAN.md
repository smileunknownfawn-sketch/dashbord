# Фінальний план приймального тестування 1.0.1

## 1. Дані
- Створити чисту папку даних.
- Створити 100 тестових розпоряджень.
- Перезапустити програму та перевірити збереження.
- Перевірити, що реальні файли не переміщуються без явної дії користувача.

## 2. Розпорядження
- Додати.
- Відкрити.
- Редагувати.
- Виконати.
- Повернути в роботу.
- Видалити в кошик.
- Відновити.
- Остаточно видалити.

## 3. Файли
- Основний документ.
- Нуль, один і декілька додатків.
- PDF, DOCX, XLSX, ZIP та зображення.
- Відкрити файл.
- Перевірити, що файл зберігається у папці правильного розпорядження.

## 4. Відповіді
- Створити відповідь.
- Додати файл відповіді.
- Додати додатки до відповіді.
- Перевірити зв'язок з правильним розпорядженням.
- Перевірити повторне відкриття після перезапуску.

## 5. Пошук
- Точний номер.
- Частина номера.
- Слово.
- Частина слова.
- Кілька слів.
- Відповідальний.
- Категорія.
- Мітка.
- Вихідний номер.
- Текст відповіді.
- Назва вкладеного файла.

## 6. Ресурси
- `sounds/opiat-rabota.mp3` реально включений у збірку.
- Звук програється під час додавання розпорядження.
- Відсутність звуку не спричиняє аварійного завершення.
- Зображення для жартівливого екрана мови реально включене у збірку.
- Зображення коректно відкривається.

## 7. Автономність
- Запуск без Інтернету.
- Пошук без Інтернету.
- Додавання/редагування без Інтернету.
- Відповіді та вкладення без Інтернету.
- Backup без Інтернету.

## 8. Backup
- Створення.
- Перевірка ZIP.
- Перевірка manifest версії 1.0.1.
- Відновлення у тестову папку.
- Помилковий/пошкоджений архів не повинен залишати тимчасові файли.

## 9. Setup
- Встановлення на чисту Windows-систему.
- Відсутність вимоги встановлювати Python.
- Відсутність вимоги встановлювати Streamlit.
- Створення ярлика.
- Перший запуск.
- Вибір папки даних D:\Дашборд.
- Повторний запуск.
- Видалення програми із збереженням даних.

## 10. Реліз
Не називати збірку фінальною, доки автоматичні тести не пройшли, EXE не створено та ресурси звуку/зображення не підтверджено всередині збірки.
