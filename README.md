# Контроль виконання розпоряджень

Вебзастосунок для реєстрації розпоряджень, контролю строків та перегляду прикріплених документів.

## Архітектура

Проєкт переведений на **Streamlit** за тією ж моделлю запуску, що й `course-01`: головна точка входу — `streamlit_app.py`, залежності — `requirements.txt`.

У застосунку вже є:

- реєстр розпоряджень;
- №, кінцевий термін та короткий опис;
- автоматичне визначення прострочених документів;
- червоне підсвічування прострочених та жовте — тих, у кого залишилося до 2 днів;
- пошук і фільтрація;
- завантаження PDF/DOC/DOCX/TXT/зображень з комп'ютера;
- локальна SQLite база даних;
- файлове сховище документів;
- вбудований перегляд PDF, TXT, зображень та базовий перегляд DOCX;
- зміна статусу «Виконано» / «У роботі»;
- видалення запису;
- демонстраційне розпорядження при першому запуску.

## Запуск у Streamlit Community Cloud

Repository: `smileunknownfawn-sketch/dashbord`

## Production-напрямок

Поточна SQLite/файлова реалізація є робочою основою для deployment, але для реальної централізованої експлуатації службових документів наступним етапом потрібно винести базу даних і файли у постійне зовнішнє сховище та додати авторизацію/ролі. Це не слід вважати захищеним службовим сховищем лише через наявність вебінтерфейсу.
