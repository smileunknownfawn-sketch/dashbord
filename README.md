# Контроль виконання розпоряджень

Службовий веб-дашборд для реєстрації розпоряджень, контролю термінів та швидкого перегляду прикріплених документів.

## Поточна версія

- темний військовий UI з фоновою фотографією та скляними панелями;
- реєстр розпоряджень: номер, кінцевий термін, короткий опис, статус;
- автоматичне визначення статусу за терміном;
- пошук та фільтри;
- додавання файлів з локального комп'ютера;
- вбудований перегляд PDF та зображень;
- збереження записів у `localStorage` браузера;
- адаптивна версія для ноутбука та планшета.

## Важливо про зберігання

Ця стартова версія працює без сервера: документи зберігаються локально у браузері через `localStorage` як Data URL. Це зручно для прототипу та локального використання на одному комп'ютері, але **не є серверним або централізованим сховищем**.

Для робочого розгортання наступним етапом варто підключити авторизацію, базу даних та окреме файлове сховище. Для службових документів це особливо важливо: доступ до файлів має контролюватися окремо від інтерфейсу.

## Запуск

Можна відкрити `index.html` у сучасному браузері. Для повноцінного deployment рекомендується роздавати проєкт через статичний web server.
